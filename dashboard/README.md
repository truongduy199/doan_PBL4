# Smart Parking Dashboard

Giao diện Web giám sát thời gian thực xây dựng bằng React + Vite + TypeScript.
Kết nối trực tiếp Firebase Realtime Database để:
- Hiển thị trạng thái 4 ô đỗ (Free, Assigned, Occupied, Wrong Vehicle).
- Danh sách các phiên đỗ xe đang hoạt động.
- Lịch sử xe vào / ra kèm chuỗi biển số.
- Tiếp nhận và xử lý yêu cầu duyệt thủ công (Manual Review).
